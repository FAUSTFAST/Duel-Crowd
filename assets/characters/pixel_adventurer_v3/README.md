# Pixel Adventurer v3 — 阶段2轮廓候选

用户设定图指导的全新、像素友好风格化低模。初始无盔甲、武器、盾；棕色蓬松发、红棕围巾、米白上衣、深裤、棕靴。此处v3是本轮第三次大形迭代，不代表已推进到用户流程的阶段3。

- 编辑源：`source/blender/adventurer_blockout.blend`。
- 静态交换文件：`adventurer_blockout.glb`，实际Blender导出后重新导入核对。
- 2367顶点、4314三角形、37个可编辑网格对象；头颈、肩袖上衣、连裆长裤、各前臂/手为各自连续主网格。
- 0骨、0动作；仅大色块材质，无正式UV/贴图、绑定、装备兼容性或变形验收。
- 手部为可读的掌/拇指体块，未分指；头发宽发块根部有意重叠。领口/衣摆/袖口等边界待阶段4结合衣厚、关节变形整理。
- 围巾、皮带、小包、靴子只是识别用大形，不是阶段3细节版。

根目录`.gdignore`隔离本轮研究，不自动导入或改动当前Godot项目。后续审核通过后再单独决定绑定/导入，不能直接换进现有角色场景。

参考图只打包在Blender的隐藏审阅集合，非本项目原创设定，不进入GLB、实际渲染或游戏纹理。重建脚本`tools/pixel_body/build_study.py`默认拒绝覆盖已有版本，手工编辑后应另存版本并保留Git检查点。

实际三视图、低分辨率与旧版比较见[研究报告](../../../docs/pixel_body_study/README.md)。
