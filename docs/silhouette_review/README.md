## 图上标志点与建模调整

正面人工量取的参考范围约为发顶 y=20、下巴 y=115、肩部 y=140、腰带 y=250、衣摆 y=324、靴口 y=470、鞋底 y=578（原图像素，边缘误差约 ±5 px）。身高归一化以鞋底到发顶为 558 px，映射到约 1.85 m。数值用于确定大形，不能代替视觉相似度审核。带头发的头部高度约为总高 17%；旧源里约七头身的“裸头顶到下巴”是另一测量口径，不应混用。

## 技术验证与限制

32 根骨骼的 rest 矩阵与旧版完全一致，不使用骨骼缩放补比例；改变的是独立网格及 idle/移动姿态。新 GLB 保留 UV、权重、切线、五段动画与原可隐藏区域；测试装备使用候选目录内的分离 GLB，资源副本不改旧目录。旧角色控制、碰撞和像素输入路由均未改写。

贴图仍沿用上一阶段十套 128px 原创工作贴图，未完成按参考重绘、细节烘焙或最终材质。当前约 13.7 万面基础角色仍需要后续拓扑/LOD 优化。手指连接、脸部、发束和布料需要人工逐顶点修形与绘制；自动化曲面不能作为达到设定图质量的证据。

本轮没有“细节完善版”截图，因为用户要求轮廓通过后再进入第二步。下一步先审核这组三视图；若仍不像，继续轮廓修正，不堆饰品掩盖差异。

## 重建

使用 Blender 4.5.9 LTS 运行 `tools/wayfarer/build_wayfarer.py -- --silhouette-study`。只有保存手工修改后才加 `--replace-generated`，该标志会覆盖**候选目录**。不带 `--silhouette-study` 是旧构建流程，不能误用。

导入后运行 `python3 tools/wayfarer/configure_imports.py --silhouette-study`，再导入；源码审计 `tools/wayfarer/audit_source.py -- --silhouette-study`，实拍 `tools/wayfarer/review_silhouette.py`，Godot 实拍 `tools/wayfarer/capture_silhouette.gd`。截图工具仅改运行夹具相机，不修改生产控制。
