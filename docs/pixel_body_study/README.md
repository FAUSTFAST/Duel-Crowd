# 像素友好基础角色：阶段 1 / 2 轮廓研究

本轮以用户提供的[冒险者设定图](../../assets/characters/wayfarer/source/reference/adventurer_concept.png)为唯一主要外观依据。目标改为适合低分辨率游戏画面与后续 sprite 输出的风格化 3D 底模：先看轮廓、动作载体比例与大色块的可读性，再考虑近看细节。

当前交付是新的独立候选 **pixel_adventurer_v3**。它是供用户审核的静态大形研究，尚未通过美术验收，也不是可替换生产角色。

实际重开源文件和GLB回读：2367顶点、4314三角形、37个可编辑网格对象，0骨、0动作。头颈、肩袖上衣、连裆长裤和前臂/手各自为连续主网格。无退化面/孤立顶点，主网格无内部非流形边；衣物开口、分离头发根部重叠及关节变形仍需阶段4审核，不能称生产拓扑完成。

## 旧版的三个主要问题

1. **细节投入与最终显示尺度不匹配。** 细长发束、表面花纹和微小五官在远景像素化后容易合并成噪点；拥有更多细节并未让角色更容易辨认。
2. **肩臂和站姿缺少自然过渡。** 正面肩臂近乎垂直，袖子、前臂、躯干关系偏僵硬；侧面胸腰与腿部偏直，缺少参考图中轻松站姿的体积变化。
3. **外观元素具备，但整体轮廓仍不像设定图。** 发型组织、头部侧影、上衣收腰与靴子比例需要先重新建立，不能继续靠增加配饰或材质掩盖。

对照原图的比例只作为近似美术测量；这张设定图的各视图不属于经过标定的严格正交照片。

## 本轮制作范围

只执行用户流程中的阶段 1 与阶段 2：分析旧版，另建基础比例、头部、发型和服装大轮廓。保留棕色蓬松短发、红棕围巾、米白上衣、深色裤子、深棕靴子、腰带与腰包这些识别点。

| 识别点 | 本轮处理 | 尚未制作的细节 |
| --- | --- | --- |
| 头部与发型 | 简化面部，以主发帽和少数发块组织外轮廓 | 细发丝、精细五官、表情 |
| 肩臂与上衣 | 调整肩袖过渡，保留卷袖、收腰、短下摆的大形 | 领口系绳、布料褶皱、缝线、织边 |
| 围巾 | 红棕颈部布块与单侧尾部作为识别轮廓 | 布料叠层、结扣与细褶 |
| 腰带与小包 | 腰部深色分区和单侧包的简化体积 | 扣具、盖片、皮革接缝 |
| 裤子与靴子 | 深浅分区、膝下松量、靴筒与鞋头轮廓 | 靴口折边、鞋带、扣带、磨损 |

围巾、腰包和靴子目前都是**大形占位**，不表示阶段 3 的服饰精修已完成。手部也保持简化，不以近距离解剖细节作为本轮目标。

v1 预览暴露的裤腰穿出、发顶尖峰、肩袖硬折与鞋头偏长已在 v2 / v3 中调整。实际查看 v3 正面、侧面与 96px 三分之四视图后，主要服装色块与围巾能够分辨；这只记录本轮观察，不代替用户对比例、发型和整体气质的审核。

## 资产与打开方法

- Blender 源文件：[adventurer_blockout.blend](../../assets/characters/pixel_adventurer_v3/source/blender/adventurer_blockout.blend)
- 静态交换资源：[adventurer_blockout.glb](../../assets/characters/pixel_adventurer_v3/adventurer_blockout.glb)

在 Blender 使用 **文件 → 打开**，选择上述 `.blend`。它包含可编辑研究模型与审阅设置；目前没有绑定骨骼，没有动画，GLB 也是静态模型。角色无盔甲、无武器、无盾牌。

本轮不修改 Godot 场景、控制、摄像机、像素渲染或装备逻辑，不接入或替换现有游戏角色。旧模型和现有游戏功能保留。

## 审核门槛与后续阶段

请先审核三视图的头身比例、发型包络、肩臂站姿、上衣体块，以及 64 / 96 / 128px 下的识别度。模型可打开或 GLB 可解析，不代表美术还原已经通过。

只有在本轮轮廓审核后，再推进：

1. **阶段 3**：完善围巾、腰带、小包、裤子和靴子的结构，继续提供预览。
2. **阶段 4**：检查拓扑与关节变形需求，准备骨骼绑定。
3. **阶段 5**：完成基础骨骼、待机、走路，以及一个基础攻击的离线动作测试。攻击仅用于检验动作载体，不增加战斗系统或其他玩法。

本轮停在阶段 2，不提前把这个大形候选称为正式基础人物。
